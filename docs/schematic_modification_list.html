02改动 1：DRV8871 的 GND 断开

U2 (DRV8871) 现在三个地脚 1 / 7 / 9(EP) 直接接 GND，全部断开，改为接到采样电阻高端。

项内容
断开U2 的 1、7、9 脚与 GND 的连线
新增网络I_MOTOR_SENSE（连接 U2.1/7/9、R41 一端、U7 的 IN+）
新增器件R41：10mΩ ±1% 1W，I_MOTOR_SENSE ↔ GND
这是本次改动风险最高的一处。DRV8871 的地被抬到采样电阻高端后， 它的逻辑电平参考也随之抬高 1A×10mΩ = 10mV（可忽略）， 但 PCB 上这一整条功率地要重新规划，不能再直接压在地平面上。

05新增：电机电压差分放大

U2 的两个输出 OUT1 / OUT2 引出，经差分放大后送 PA2。

位号器件封装连接
U9MCP6002（用 A 通道）SOP-81→PA2（OUT）　2→R46/R47 节点（IN−）　3→R48/R49 节点（IN+）　4→GND　8→3V3
R46 / R48100kΩ ±1%0805分别从 OUT1 / OUT2 接入
R47 / R4913kΩ ±1%0805R47 为反馈（接 OUT），R49 接 1.65V

U9 不能用 LM358。LM358 在 3.3V 供电下输出最高只有约 1.8V，正转时信号被削顶。 必须用轨到轨运放：MCP6002 或 SGM8542。

06新增：加热驱动

位号器件封装连接
Q2AO3400（N-MOS）SOT-231→Rg　2→I_HEAT_SENSE　3→J2.2
Rg100Ω0805PB0 ↔ Q2 栅极
Rgs10kΩ0805Q2 栅极 ↔ GND

Rgs 的 10k 下拉不能省。MCU 上电复位期间 GPIO 是高阻态， 没有下拉 MOS 可能被干扰误导通，加热棒直接全功率工作。

08新增：加热电压采集

测的是 Q2 漏极对地电压，软件里再用 12 − V_drain 反算加热棒电压。

位号器件封装连接
R43 / R4433kΩ / 11kΩ ±1%0805分压 1:4
R5210kΩ0805RC 滤波串联电阻
C361μF0805RC 滤波，时间常数 10ms
为什么测漏极而不是加热棒两端：加热棒一端固定接 12V， 另一端（漏极）才是 PWM 变化的点。导通时 ≈0V、关断时 ≈12V， 滤波后的平均值 = 12×(1−D)，反算得到加热棒实际电压 12×D。

11改完后逐项检查

  • U2 的 1 / 7 / 9 脚是否已从 GND 断开，全部接到 I_MOTOR_SENSE
  • R41 / R42 是否为 10mΩ（不是 10k），封装 1206
  • U7 / U8 的 1 脚接 IN+（采样高端）、3 脚接 IN−（GND），4 脚才是 OUT，别按官方手册的管脚号接
  • U9 是 MCP6002，不是 LM358
  • 差分电阻：R46/R48 = 100k，R47/R49 = 13k，四颗都要 ±1%
  • V_REF_1V65 是否有 C32 100nF 滤波
  • Q2 是 AO3400（N 沟道），源极朝下接地，漏极朝上接加热棒
  • Q2 栅极是否有 Rgs 10k 下拉到 GND
  • J2 的 1 脚接 +12V，2 脚接 Q2 漏极（别接反）
  • R45（NTC 上拉）是 10k，不是 100k
  • 五个 ADC 引脚：PA2 / PA3 / PA4 / PA5 / PB1 是否都接对了
  • PB0 是否接在 TIM3_CH3（加热 PWM）
  • 所有新增器件的 AddIntoPcb 是否为 true（否则不会进 PCB）
