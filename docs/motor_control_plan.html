Software Design Brief

双传感器电机控制平台
软件方案

面向学生实验的电机控制设备：同一电机轴上并行安装霍尔编码器与 AS5600 磁编码器， 支持两套方案独立运行、对比差异，并可扩展为多传感器融合控制。

平台 STM32F103C8T6 / 72 MHz 版本 v1.0 草案 日期 2026-10-31
01

项目定位

这是教学平台，不是量产产品。三条评价标准决定所有设计取舍。

  • 可对比 —— 学生要能亲眼看到两种传感器在同一台设备上表现出的差异，软件不能把这个差异抹平。
  • 可切换 —— 三种工作模式由上位机实时切换，切换过程不能要求重新烧录固件。
  • 可扩展 —— 老师后续要在此基础上实现融合算法，底层必须留出清晰的接口，换算法不碰驱动。
设计红线：保留传感器的原始特性。 霍尔编码器是增量式的、上电零点未知、会累积丢步 —— 这些"缺点"正是教学内容。 如果软件给它加自动归零、插值平滑之类的补偿，学生就看不出现象了。差异必须如实暴露出来。

两种传感器的本质差异

这是整个实验的核心知识点，也是融合算法存在的理由。

维度霍尔编码器AS5600 磁编码器
类型 增量式，只输出脉冲 绝对式，直接输出 0–360° 角度
上电时刻 零点未知，软件从 0 开始累计 立刻读出真实角度
分辨率 13 线 × 4 = 52 计数/圈
≈ 6.9° / 计数		 4096 计数/圈
≈ 0.088° / 计数
累积误差 丢脉冲即永久丢失，不可恢复 每周期重读绝对值，不累积
更新延迟 极低（硬件计数，纳秒级读取） I2C 传输 + 内部转换，0.5–1 ms 量级
低速表现 量化噪声大，速度估计抖动明显 平滑，但延迟会限制带宽
为什么融合有价值：磁编码器提供长期准确的位置基准（无漂移）， 霍尔提供高频动态响应（无通信延迟）。两者互补，正是互补滤波或卡尔曼滤波的典型场景。
03

资源分配

当前 CubeMX 已配置 TIM2、TIM3、USART1、I2C1。控制周期时基需要补一个 TIM4。

外设引脚用途关键参数
TIM2 PA0 / PA1 霍尔编码器接口 Encoder TI12 · PSC 0 · ARR 65535
TIM3 PA6 / PA7 PWM 输出（CH1 / CH2） PSC 0 · ARR 3599 → 20 kHz
TIM4 无引脚 控制周期时基 PSC 71 · ARR 999 → 1 kHz 中断
I2C1 PB6 / PB7 AS5600 角度读取 400 kHz · 从机 0x36
USART1 PA9 / PA10 上位机通信 115200 · 8N1 · 中断接收
时基为什么必须用 TIM4 而不是 SysTick： HAL 库的 HAL_Delay() 依赖 SysTick，如果在 SysTick 中断里跑 1 kHz 控制循环， 会拖慢整个 HAL 时基并引发优先级问题。TIM4 不占用任何引脚（不使能输出通道）， 作为纯定时中断源最干净。

自下而上四层，每层只依赖下一层。融合算法在控制层之上，换算法不影响驱动。

统一数据接口

三种模式（霍尔 / 磁编码器 / 融合）对上位呈现同一种数据结构，控制层不需要知道数据来自哪里。

/* 所有传感器输出统一为这个结构 */
typedef struct {
    float    angle;      // 绝对角度，弧度，0 ~ 2π
    float    speed;      // 角速度，rad/s
    uint32_t tick;       // 采样时刻，ms
    uint8_t  valid;      // 0 = 数据无效
    uint8_t  fault;      // 磁铁缺失 / 信号异常
} sensor_t;

/* 每路传感器实现同一组函数 */
void hall_init(void);
void hall_sample(sensor_t *out);
void mag_init(void);
void mag_sample(sensor_t *out);
void fused_sample(sensor_t *out);   // 融合结果复用同一接口
这一层是这个项目最容易返工的地方。 如果先写死霍尔、把计数值直接塞进 PID，等老师要融合时发现两套数据结构对不上， 整个控制层都要重写。所以第一天就把 sensor_t 定下来。
05

三种工作模式

由上位机命令实时切换，切换时重新初始化控制环积分项，避免冲击。

MODE 0
霍尔独立
仅用增量编码器。可做速度闭环； 位置控制需软件累计，会有漂移和丢步现象。 适合演示"增量式的局限"。
MODE 1
磁编码器独立
仅用 AS5600。上电即知绝对位置， 可做速度 + 位置双环。 适合演示"绝对式的优势"。
MODE 2
融合
两路同时采样，经融合算法输出。 位置基准来自磁编码器， 高频动态来自霍尔。

模式 2 之外，两路传感器仍在持续采样——上位机要能同时看到两路原始数据，方便学生对比。

06

关键设计

6.1 采样时序与时间预算

控制周期 1 ms，所有动作必须在预算内完成。AS5600 的 I2C 通信是唯一的大开销。

任务耗时估算说明
读取 TIM2 计数≈ 1 μs直接读寄存器，无开销
AS5600 读角度150 – 250 μs400 kHz I2C，2 字节 + 寄存器地址
速度 / 融合计算30 – 60 μs无 FPU，浮点靠软件模拟
PID + 输出20 – 40 μs两路环 + 限幅
合计≈ 0.30 ms占 1 ms 周期的 30%，余量充足
F103C8T6 没有硬件浮点单元（FPU）。 所有 float 运算都是软件模拟，一次乘加约 100 个时钟周期。 1 ms 内做几百次浮点运算是安全的，但不要在里面写 pow()、sin()、sqrt() 这类库函数， 也不要在中断里做大量格式化输出。

6.2 速度估计

两种传感器都必须用差分求速度，绝对不能直接用绝对位置除以时间。

/* 霍尔：16 位计数器，强转 int16_t 自动处理回绕 */
int16_t now  = (int16_t)__HAL_TIM_GET_COUNTER(&htim2);
int16_t diff = (int16_t)(now - last);
last = now;

/* 换算：diff 是电机轴计数，需除以线数×倍频，再除以减速比 */
float rev  = (float)diff / CPR;              // CPR = 线数 × 4
float rpm  = rev / (PERIOD_MS / 60000.0f);   // 转/分

/* AS5600：角度差分 + 环绕处理 */
float d = mag_now - mag_last;
if (d >  PI) d -= 2.0f * PI;
if (d < -PI) d += 2.0f * PI;
float omega = d / (PERIOD_MS / 1000.0f);     // rad/s

霍尔 52 计数/圈，1 ms 采样时最低可分辨速度约为 1 / 52 / 0.001 ≈ 19 rev/s ≈ 1150 RPM（电机轴）—— 低速下速度值会阶跃跳动，这是学生应该观察到的现象，不要用滤波抹平。

6.3 融合算法

方案默认实现互补滤波，接口预留卡尔曼。老师若要更"特殊"的算法，只需替换 fused_sample() 的内部实现。

/* 互补滤波：低频信任磁编码器，高频信任霍尔 */
#define ALPHA  0.98f        // 1 kHz 下时间常数约 50 ms

static float fused_angle;

void fused_sample(sensor_t *out)
{
    /* 用霍尔增量做高频预测 */
    float delta = normalize(hall_angle - hall_last);
    float pred  = normalize(fused_angle + delta);

    /* 用磁编码器绝对角度做低频校正 */
    float corr  = normalize(mag_angle - pred);
    fused_angle = normalize(pred + (1.0f - ALPHA) * corr);

    out->angle = fused_angle;
    out->speed = hall_speed;   // 速度直接用霍尔，延迟更低
}

α 的物理意义：α 越接近 1，越信任霍尔的高频，但长期会跟着霍尔漂；α 越小，越信任磁编码器的绝对值，但响应变慢、会把 I2C 延迟引入系统。α = 0.98 对应约 50 ms 的校正时间常数，是个稳妥起点。

6.4 控制环结构

串级结构：外环位置，内环速度。模式 0 只跑速度环（霍尔位置不可靠）。

目标速度 ──→ [速度 PID] ──→ PWM 占空比 ──→ 电机
              ↑                    │
              └──── 传感器速度 ←────┘

目标角度 ──→ [位置 P] ──→ 目标速度 ──→ [速度 PID] ──→ PWM
              ↑                            ↑
          传感器角度                    传感器速度
  • 输出限幅 —— PID 输出必须钳在 ±ARR 之间，否则积分饱和后超调严重
  • 积分抗饱和 —— 输出被限幅时停止积分累加（clamping）
  • 模式切换清积分 —— 切换传感器或控制模式时，把积分项清零，避免冲击
  • 启动斜坡 —— 目标值从 0 线性爬升，避免大电流冲击

6.5 保护逻辑

实验室设备，学生会堵转、会乱发指令。保护比性能重要。

保护项判据动作
堵转占空比 > 60% 且 |速度| < 阈值，持续 500 ms切断 PWM，进故障态
超速|速度| 超过额定 1.2 倍立即降占空比
磁铁缺失AS5600 STATUS 寄存器 MD 位为 0标记 fault，模式 1/2 不可用
指令超时上位机 1 s 无有效命令自动停机（防止失控）
上电自检初始化时读取两路传感器失败则只开放可用模式

6.6 AS5600 读取细节

  • I2C 从机地址 0x36（7 位）
  • 角度寄存器 0x0C（高 4 位）与 0x0D（低 8 位），合并为 12 位原始角度
  • 状态寄存器 0x0B：bit5 = MD（检测到磁铁）、bit4 = ML（磁场太弱）、bit3 = MH（磁场太强）
  • 12 位对应 0–4095，换算：angle_rad = raw * 2π / 4096
  • 若一次读取失败，沿用上次值并置 valid = 0，连续失败 3 次进故障态——不要直接清零，否则会被 PID 当成跳变

08

实施路线

按依赖顺序推进，每一步都有可验证的产出。不要跳步——速度测不准，PID 参数怎么调都是玄学。

P0
时基与骨架
配 TIM4 产生 1 kHz 中断，建立空的调度框架，串口先能打印心跳。
✓ 串口每 100 ms 输出一次 tick 计数
P1
双传感器自检
手动转动电机轴，同时读取霍尔计数与 AS5600 角度，串口打印。
✓ 手转一圈，两个读数同步变化且比例正确
P2
开环 PWM + 测速
固定占空比让电机转起来，用编码器算出转速，验证换向与方向判断。
✓ 占空比与转速大致成线性，方向正确
P3
速度闭环
先用磁编码器（噪声小）调通速度 PID，再把同一套参数套到霍尔上，对比差异。
✓ 阶跃响应无明显超调，稳态误差可接受
P4
位置闭环
加上外环位置控制。此时霍尔方案的漂移问题会暴露出来，正好作为教学案例。
✓ 指定角度定位，磁编码器方案无静差，霍尔方案有累积偏差
P5
融合模式
实现互补滤波，与单传感器方案做对比测试：位置精度、响应速度、抗丢步能力。
✓ 融合结果的漂移小于霍尔、延迟小于磁编码器
P6
上位机联调
协议对接、模式下发、数据可视化，做成学生可操作的界面。
✓ 学生可通过上位机完成三种模式的切换与观测
