## 2. 五路模拟量

| 通道 | 引脚 | 外设 | 测量对象 | 电路 | 换算公式 | 量程 |
|---|---|---|---|---|---|---|
| 1 | PA2 | ADC1_IN2 | 电机电压 | 差分放大 ×0.13 + 1.65V 偏置 | `V = (ADC×3.3/4095 − 1.65) / 0.13` | ±12 V |
| 2 | PA3 | ADC1_IN3 | 电机电流 | 10mΩ 采样 + INA180A3（×100） | `I = ADC×3.3/4095 / 100 / 0.01` | 0 ~ 3.3 A |
| 3 | PA4 | GPIO | 铜块温度 | DS18B20 单总线 | 1-Wire 读寄存器，见第 6 节 | −55 ~ 125 °C |
| 4 | PA5 | ADC1_IN5 | 加热电流 | 10mΩ 采样 + INA180A3（×100） | `I = ADC×3.3/4095 / 100 / 0.01` | 0 ~ 3.3 A |
| 5 | PB1 | ADC1_IN9 | 加热电压 | 分压 33k/11k + RC 滤波 | `V_drain = ADC×3.3/4095 × 4`；`V_heat = 12 − V_drain` | 0 ~ 12 V |

**注意**：加热电压测的是 MOS 漏极对地平均电压。PWM 导通时漏极≈0V，关断时≈12V，所以 `V_heat = 12 − V_drain = 12 × 占空比`。

## 3. 控制信号

| 引脚 | 网络 | 外设 | 用途 |
|---|---|---|---|
| PA0 / PA1 | ENCODER_A / ENCODER_B | TIM2（Encoder 模式） | 编码器测速，四倍频 |
| PA6 / PA7 | IN1 / IN2 | GPIO 推挽输出 | DRV8871 方向控制（IN1/IN2 组合决定正反转/刹车） |
| PB0 | HEAT_PWM | TIM3_CH3（20 kHz） | 加热 MOS 开关，占空比控制功率 |
| PA9 / PA10 | RXD / TXD | USART1 | 与上位机通信 |
| PB6 / PB7 | I2C1_SCL / I2C1_SDA | I2C1（400kHz） | AS5600 磁编码器 |

**DRV8871 真值表**：

| IN1 | IN2 | 输出状态 |
|---|---|---|
| 0 | 0 | 滑行（coast） |
| 1 | 0 | 正转 |
| 0 | 1 | 反转 |
| 1 | 1 | 刹车（brake） |

**PWM 调速**：把 PWM 打在 IN1 或 IN2 上，另一个拉低。例如正转调速：IN1 = PWM，IN2 = 0。

## 7. CubeMX 配置要点

```
SYSCLK      : HSE 8MHz × 9 = 72MHz
APB1        : 36MHz（TIM2/TIM3 时钟 72MHz）
APB2        : 72MHz

ADC1        : 连续扫描 4 通道（IN2/IN3/IN5/IN9），12 位
              采样时间建议 71.5 周期以上（高阻抗源）
              或用 DMA 循环模式

TIM2        : Encoder Mode，CH1=PA0 / CH2=PA1，四倍频计数

TIM3        : CH3 = PB0，PWM Generation
              预分频 0 → 72MHz 计数，ARR=3599 → 20kHz

USART1      : 115200 8N1，PA9=TX / PA10=RX
I2C1        : 400kHz 快速模式，PB6=SCL / PB7=SDA

PA4         : GPIO_Output（开漏），DS18B20 单总线
PA6 / PA7   : GPIO_Output 推挽，DRV8871 方向控制
```

## 8. 编程注意事项

**1. DS18B20 时序敏感**

- 1-Wire 时序是微秒级，读取期间要关全局中断，否则 PWM 中断会打断时序
- 温度转换需要 750ms（12 位精度），不能阻塞等，用状态机
- 上电后先复位、读 ROM，确认器件存在再读温度

**2. 加热电压的符号**

- `V_heat = 12 − V_drain`，占空比越大 V_heat 越大
- PWM 频率 20kHz（50us 周期），RC 时间常数 10ms 是其 200 倍，滤波后是平滑直流

**3. 电机电路**

- DRV8871 限流 1.5A，堵转时会被限流，不要靠它做保护
- 换向时要先刹车（IN1=IN2=1）再反向，避免电流冲击
- 编码器用 TIM2 硬件编码器模式，四倍频后分辨率 = 线数 × 4

**4. ADC 采样**

- 四路 ADC 共用 ADC1，建议 DMA 循环 + 定时器触发，避免 CPU 干预
- 电流通道有 PWM 纹波，软件再做滑动平均（8~16 点）

**5. 上电顺序**

- PB0 上电默认是浮空输入，R50 下拉保证 MOS 关断
- 初始化时先把 PA6/PA7 拉低，再配置外设
