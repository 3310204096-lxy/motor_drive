电机 + 加热控制板
方案定稿

STM32F103C8T6 + DRV8871 + AO3400，采集驱动输出侧电压、支路电流与温度共 5 路模拟量， 支持功率计算与电流环控制。

03

电机电压：差分放大

这是全板最讲究的一路。H 桥输出正转 +12V×D、反转 −12V×D，ADC 只认 0~3.3V，必须加偏置把负半周抬上来。

OUT1 ──[R1 100k]──┬──(−)
                  │
             [R2 13k]── Vout ──→ PA2
                  │
OUT2 ──[R3 100k]──┬──(+)
                  │
             [R4 13k]── 1.65V

标准差分拓扑，增益 = R2/R1 = 13k/100k = 0.13，偏置由 R4 端接入 1.65V：

Vout = 0.13 × (OUT2 − OUT1) + 1.65

正转满占空比 (+12V) → 1.65 + 1.56 = 3.21 V
零电压           → 1.65 V
反转满占空比 (−12V) → 1.65 − 1.56 = 0.09 V
元件值说明
R1 / R3100kΩ ±1%输入电阻，12V 加在上面电流仅 0.12mA
R2 / R413kΩ ±1%反馈/偏置电阻，必须与 R1/R3 配对
Vref1.65V两个 10kΩ 从 3.3V 分压 + 100nF
运放MCP60023.3V 供电，轨到轨，SOP-8
运放不能用 LM358。LM358 在 3.3V 供电下，输出最高只能到约 1.8V， 正转时信号会被削顶。必须用轨到轨（Rail-to-Rail）运放，如 MCP6002 / SGM8542。

05

加热驱动与电压采集

12V ──[加热棒]──┬── Q2 漏极 (AO3400)
                │
           Q2 源极 ──[10mΩ]── GND
                │
           [分压 33k/11k] ── [RC 10k+1uF] ── PB1

PB0 ──[Rg 100Ω]──┬── Q2 栅极
                 │
             [Rgs 10k]
                 │
                GND

加热电压怎么算：测的是 MOS 漏极对地平均电压。

PWM 导通 → 漏极 ≈ 0V
PWM 关断 → 漏极 ≈ 12V
平均电压 = 12 × (1 − D)
加热棒两端电压 = 12 − 平均 = 12 × D

RC 滤波时间常数取 10ms（10kΩ + 1μF），远大于 20kHz PWM 的 50μs 周期（200 倍），滤波后是平滑直流。选 20kHz 是为了同时满足电机 PWM 需求——超出人耳听觉，电机不会有啸叫。

元件选型依据
Q2AO3400（SOT-23）1A 时功耗 33mW，完全不热
Rg / Rgs100Ω / 10kΩRgs 下拉不能省，防上电误导通
分压33k / 11k12V → 3V，功耗 3.3mW

R_ntc = 10k × Vadc / (3.3 − Vadc)
T(°C) = 1 / (1/298.15 + ln(R_ntc/10000) / 3950) − 273.15

09

PCB 改动

改动难度说明
DRV8871 的 GND 串采样电阻高三个 GND 脚全部改接，功率地重走
差分放大电路布局中高R1/R3、R2/R4 必须严格对称，靠近运放
加热通路中12V 大电流走 40 mil 以上
INA180 ×2中紧贴各自采样电阻
NTC 与分压低远离功率区，避免受热影响
地平面重做高功率地与信号地单点汇合
本次改板的核心风险仍是地。采样电阻把功率地"切开"， 若处理不当会出现：加热一开 ADC 就跳、电机一转串口就乱。 NTC 要远离功率器件，否则读到的是板子温度而不是空气温度。
10

软件要点

ADC 采集

ADC1 扫描 5 通道 + DMA 循环

采样率：每通道 2 kHz（总 10 kHz）
—— 加热电压那一路自带 10ms RC 滤波，软件不用再滤

电流滤波

PWM 斩波会造成 10~20% 电流纹波，需一阶低通：

y[n] = α·x[n] + (1−α)·y[n−1]
α = 0.1 → 截止约 160 Hz（2 kHz 采样下）

功率与占空比补偿

P_motor = V_motor × I_motor
P_heat  = V_heat  × I_heat

温度闭环：
  PID(目标温度, 实测温度) → 目标功率
  D = P_target × R_heat / (V_bus)²     ← 电压波动补偿

保护

  • 过流：任一电流超阈值 → 立即关 PWM
  • 过温：NTC 超 120°C → 停止加热（空气测温，留 30°C 余量）
  • 欠压：母线 < 10V → 停止加热
  • 堵转：电流大且速度接近 0，持续 500ms → 停机
11

实施顺序

  • 第一步：原理图加器件（约 28 个），连线，编译检查
  • 第二步：更新 PCB，重新布局 —— 布局从零开始，因为地要重新规划
  • 第三步：布线，重点处理功率地与模拟地
  • 第四步：DRC + 检查
  • 第五步：打样验证（建议先只焊电源和 MCU，验证 3.3V 和 ADC 基准）
一句话：这不是"在现有板上加几个器件"，而是"重新设计一版"。 现有布局的电源区、主控区的相对位置可以沿用，但走线和铺铜必须重做。
