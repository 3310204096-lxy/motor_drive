Design Proposal · V2

电机 + 加热控制板
功能扩展方案

在现有 STM32F103C8T6 + DRV8871 板基础上，补齐老方案中的电压/电流采集与加热控制功能， 用于教学实验台。

平台 STM32F103C8T6 · 72 MHz 驱动 DRV8871 + AOD4184 日期 2026-11-05
01

需求对照

老方案基于 STM32G431 + L298N 双 H 桥，本次保留功能目标、更换实现方案。

功能老方案新方案
电机驱动L298N 一个 H 桥（压降 2V）DRV8871（压降 0.5V，效率高）
加热驱动L298N 另一个 H 桥AOD4184 + PWM（电阻负载不需要 H 桥）
母线电压差分放大（衰减 0.2）33k/11k 分压 + ADC
电机电流5mΩ + 运放（增益不足）10mΩ + INA180A3（增益 100）
加热电流同上10mΩ + INA180A3
编码器2 路1 路（TIM2，硬件计数）
温度检测NTC 接口本版不做（开环加热）
本版范围：一路电机（速度/位置闭环）+ 一路加热棒（PWM 功率控制）+ 3 路模拟量采集。 温度传感、双电机留待后续版本。

03

模块设计

3.1 电机驱动（沿用）

DRV8871，峰值 3.6A，IN1/IN2 双 PWM 输入，支持正反转。限流电阻 R3 = 30kΩ 当前对应 0.82A。

限流需要调整。若配 3W 电机（额定 0.8A / 堵转 2A），0.82A 正好卡在额定值，启动无力。 建议 R3 改为 16kΩ，限流 1.5A。

3.2 加热驱动（新增）

12V ──[加热棒]──┬── Q2 漏极 (AOD4184)
                │
           Q2 源极 ──[10mΩ]── GND

PB0 ──[Rg 100Ω]──┬── Q2 栅极
                 │
             [Rgs 10k]
                 │
                GND
器件参数说明
Q2AOD4184 · TO-25240V / 50A / Rds 12mΩ@3.3V，逻辑电平
Rg100Ω 0805栅极限流
Rgs10kΩ 0805下拉，防止上电误导通

为什么不用 H 桥：加热棒是纯电阻，不需要换向。单个低边开关就能 PWM 调功率，比 L298N 省一半器件、少 2V 压降。

3.3 模拟量采集（3 路）

① 母线电压

12V ──[33k]──┬── PA2 (ADC1_IN2)
             │
          [11k]
             │
            GND ──[100nF]── 同上节点

分压比 1:4，12V → 3.0V。功耗 3.3mW，精度约 1.5%。

② 电机电流

DRV8871 GND(1,7,9) ──┬──[10mΩ]── GND
                     └── INA180 IN+
GND ───────────────────── INA180 IN−
INA180 OUT ────────────── PA3 (ADC1_IN3)

③ 加热电流

Q2 源极 ──┬──[10mΩ]── GND
          └── INA180 IN+
GND ────────── INA180 IN−
INA180 OUT ─── PA5 (ADC1_IN5)
参数值说明
采样电阻10mΩ ±1% 1W 12062A 时压降 20mV，功耗 40mW
放大器INA180A3（增益 100）2A → 2.0V 输出
量程0 ~ 3.3A超出则饱和，不会损坏
分辨率≈ 0.8 mA12 位 ADC
采样点都在低边（地侧），共模电压接近 0V，INA180 工作最稳定。 代价是功率地要经过采样电阻才能回到主地平面，PCB 布线需单独处理。

06

PCB 改动

现有板已完成布线与铺铜，本次改动需要局部重布。

改动难度说明
DRV8871 的 GND 断串采样电阻高三个 GND 脚（1/7/9）全部改接到 10mΩ 高端，功率地要重走
加热通路（MOS + 采样 + 接口）中从 12V 引出，走 60 mil 以上
INA180 ×2 放置中紧贴各自采样电阻，输出线走模拟区
分压电阻 + 滤波低靠近 PA2
地平面重做高功率地与信号地单点汇合，避免加热电流穿过 MCU 地
最大的风险在地。采样电阻把功率地"切开"了，处理不当会出现： 加热一开、ADC 读数就跳；或者电机一转、串口就乱码。这是本次改板最需要验证的地方。
07

软件需求

ADC 采集

ADC1 扫描模式 + DMA，3 通道连续转换
采样率 10 kHz（每个通道约 3.3 kHz）

换算：
  V_bus = adc[0] × 3.3 / 4095 × 4.0
  I_motor = adc[1] × 3.3 / 4095 / 100 / 0.01
  I_heat  = adc[2] × 3.3 / 4095 / 100 / 0.01

电流滤波

PWM 斩波会造成 10~20% 的电流纹波，直接读会跳。建议一阶低通：

y[n] = α × x[n] + (1 - α) × y[n-1]
α = 0.1   →  截止频率约 160 Hz（10 kHz 采样下）

加热功率控制

目标功率 P_target → 占空比

D = P_target × R_heat / V_bus²

用实测 V_bus 补偿，电源电压波动时功率基本不变。

保护

  • 过流：I_motor 或 I_heat 超阈值 → 立即关 PWM
  • 堵转：电流大且速度接近 0，持续 500ms → 停机
  • 欠压：V_bus < 10V → 停止加热，提示
  • 加热超时：连续加热超过设定时间 → 强制关闭（防止失控）
