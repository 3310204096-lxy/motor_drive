P0致命问题

1. USB 的 5V 和 MP2315 的 5V 输出直接并联

Type-C 的 VBUS 经保险丝 U6 后，接到的正是 MP2315 降压输出的 +5V 网络。两个独立的 5V 源短接在一起。

VBUS 网络 ($7N292)：USB1.2 · USB1.11 · U6.1 U6.2 → +5V +5V 网络：L1.2（MP2315 输出）· U4.3（LDO 输入）· C16/C17/C20/C21 …

后果：12V 适配器和 USB 线同时插入时，USB 主机的 5V 和 MP2315 的 5V 会互相灌电流。轻则保护、重则烧掉电脑的 USB 口——主机端只有 500mA 限流，而 MP2315 能输出 3A。

改法：两路各串一个肖特基二极管（SS34 / B5819W）做 ORing，或者中间加负载开关（如 TPS22918）做电源切换。最简单的是把 USB 的 VBUS 改成只给 ST-Link 供电、不进系统 5V。

2. VBAT 悬空

U1 的 1 脚（VBAT）网络上只有它自己一个点，没接电源也没接电容。

VBAT：U1.1 ← 全网只有这一个点

STM32F103 数据手册明确要求：不使用 RTC 时，VBAT 应接到 VDD，或至少加 100nF 到地。悬空会让备份域处于不确定状态，可能引入噪声，也可能影响上电复位。

改法：VBAT 直接接 +3V3（最简单），或者加一颗 100nF 到地。

P1严重问题

3. D+ 上拉用了 NPN，输出电压不够

Q1 是 SS8050（NPN），接法是集电极接 3.3V、发射极经 1.5kΩ 到 D+、基极受控——这是射极跟随器。

Q1.3 (C) → +3V3 Q1.2 (E) → R36(1.5k) → DP Q1.1 (B) → R32 / R35 / R38 分压网络

两个问题：

  • 射随输出 = 3.3V − VBE ≈ 2.6V，而 USB 全速设备要求 D+ 上拉后达到 3.0~3.6V，2.6V 处在识别边缘
  • 逻辑反了：NPN 是基极高电平导通，而 ST-Link 固件通常按 PNP（低电平连接）设计
改法：换成 PNP（SS8550），发射极接 3.3V、集电极经 1.5kΩ 到 D+、基极下拉。这样导通时 D+ 直接拿到 3.3V，逻辑也和标准一致。

4. NRST 上挂了 1.1μF，复位沿过缓

NRST 网络上有两个电容并联：C26（100nF）+ C1（1μF），同时还并着两个 MCU 的内部上拉。

NRST：U1.7 · U5.7 · SW1.1 · C26.1(100nF) · C1.1(1uF) · R1(10k) · R19(100k) · R27.2

1.1μF 配 20kΩ 等效上拉，时间常数约 7.6ms。复位解除时电压缓慢爬升，施密特触发器可能多次翻转，表现为"偶尔复位不成功"或者"上电跑飞"。

改法：C1 改成 100nF，或者直接删掉（C26 已足够）。

5. C20 / C21 / C22 / C23 没有值

这四颗是 LDO 前后的滤波电容，目前值和 LCSC 料号都是空的。

C20："" "" C0805 C21："" "" C0805 C22："" "" C0805 C23："" "" C0805

BOM 里没法采购，PCB 上也看不出该用多大。

改法：按 LDO 常规配置填值——输入侧 10μF + 100nF，输出侧 22μF + 100nF。

6. MP2315 输出 4.34V，LDO 压差不足

反馈电阻 R10 = 40.2kΩ（上）、R11 = 9.09kΩ（下）。按 MP2315 的 VFB = 0.8V 计算：

Vout = 0.8 × (1 + 40.2 / 9.09) = 0.8 × 5.42 ≈ 4.34V

U4 是 3.3V / 1A 的 LDO，压差只有 1.04V。AMS1117 类器件满载需要 1.1~1.3V dropout，重载时会掉出稳压区，3.3V 跟着往下掉。

建议：先确认 MP2315 的 VFB 是不是 0.8V（查数据手册）。如果是，把 R11 改成 8.06kΩ（Vout ≈ 4.79V）或 R10 改成 47kΩ（Vout ≈ 4.94V），给 LDO 留足压差。

你之前说分压确认过，如果确实是按 4.34V 的目标设计的（比如 LDO 是低压差型号），这条忽略。

P2规范问题

7. X2 的负载电容偏小

X2 规格是 8MHz / 负载电容 20pF，但配的 C24 / C25 只有 20pF。实际负载电容是两电容串联再加上杂散电容：

C_load = (20×20)/(20+20) + Cstray ≈ 10 + 4 = 14pF ← 需要 20pF

X1 那组是对的（规格 12pF，配 18pF，算下来 13pF）。

改法：C24 / C25 改成 33pF，算下来 16.5 + 4 ≈ 20.5pF。

8. U5 的 15 脚和 26 脚并联在 SWCLK 上

T_JTCK_SWCLK：U5.15 (PA5) · U5.26 (PB13) · R34.2

两个 IO 直接短接。如果固件把两个都配成推挽输出，会互相打架；只有一个做输出、另一个做输入才安全。

确认：看 ST-Link 固件的引脚配置，或者查旧板的原理图是不是也这么接的。

9. USB1 的封装名和器件对不上

器件描述是「TYPE-C 母座 16P 4脚插件带定位柱」，但封装名是 USB-C-SMD_TYPE-C-6PIN-2MD-073（6PIN）。实际焊盘编号到 14，说明封装确实有 14 个焊盘——名字写错了。

确认：打开封装看一眼，确保焊盘数和器件引脚数一致，别到时候贴不上。

10. R3 缺 LCSC 料号

R3 = 30K（格式也和其他不一致，应写 30kΩ），LCSC Part Name 为空。

补料号即可。

11. BOOT0 / BOOT1 两个 MCU 并联

BOOT0：U1.44 · U5.44 · R4.1 · R16.2 BOOT1：U1.20 · U5.20 · R5.2 · R24.1

给 ST-Link 升级固件需要拉高 BOOT0 时，主控也会一起进入系统存储器启动，程序停止。

不改也能用（升级时不跑主控），想干净就在原理图里把 U5 的拆成独立网络。

12. 无 ESD 保护、无电源反接保护

USB 的 D+/D− 经 10Ω 直接进 MCU，没有 TVS；12V 从 DC 座直接进 MP2315，没有反接保护。

教学板可以不加，但学生反复插拔 USB、接反电源的概率不低。加两颗 TVS（如 USBLC6-2SC6）和一个 P-MOS 反接保护，成本不到 2 元。
