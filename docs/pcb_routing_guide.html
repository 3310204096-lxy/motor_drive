⚠

布线前必须先修一个原理图问题

两个晶振被短接在同一个网络上。

PCB 里 OSC_IN 和 OSC_OUT 各挂了 6 个点：

网络连接点
OSC_INC24.2 · U5.5 · U1.5 · X1.1 · X2.1 · C11.1
OSC_OUTC25.2 · U5.6 · U1.6 · X1.3 · X2.2 · C12.1

这意味着 U1（主控）和 U5（ST-Link）的晶振引脚并联，X1 和 X2 两颗晶振也并联。后果：

  • 输出对驱 —— STM32 的 OSC_OUT 是推挽输出，两个 MCU 的输出直接对撞
  • 负载电容翻倍 —— C11(18pF) 和 C24(20pF) 并在同一侧，实际负载 38pF，远超晶振设计值
  • 大概率不起振，或者起振频率偏移，两个 MCU 都跑飞
修复：把 ST-Link 那一组的网络改名。在原理图里把 X2 / C24 / C25 / U5.5 / U5.6 上的网络分别改成 OSC_IN_STL 和 OSC_OUT_STL，然后 设计 → 更新 PCB。
改完 PCB 上这两个网络各剩 3 个点（晶振 + 电容 + MCU 引脚），才是正常结构。

+3V3 37 点

这是全板最大的一张网，不要一根线连到底。按三个扇区走：

  • 主干：U4.2 / U4.4（LDO 输出）→ 分两路，一路到主控区、一路到 ST-Link 区，25 mil
  • MCU 电源脚：U1 的 9 / 24 / 36 / 48 脚，U5 的 1 / 9 / 24 / 36 / 48 脚，每脚 15 mil
  • 上拉与连接器：H1.1、H2.1、H4.3、LED 上拉等，10–12 mil
GND 不要走线。底层整片铺铜当地平面，所有 GND 焊盘就近打过孔下地。顶层的 GND 也用铺铜填充，不画线。
03

P1 · 去耦电容

这一组是自动布线最容易做坏的。每个电容到对应电源脚的距离必须 < 3 mm，线宽 15–20 mil，走直线不要绕。

MCU电源脚去耦电容
U1（主控）9 / 24 / 36 / 48C2 C3 C4 C5 C6 C7 C8
U5（ST-Link）1 / 9 / 24 / 36 / 48C22 C23 C27 C28 C29 C30
布完立刻锁定。选中这些线 → 右键 → 锁定，否则自动布线会把它们重新绕一遍，等于白做。
04

P2 · USB 差分对

路径要当成一条连续的差分通道来看，中间经过 10Ω 串阻：

段D+D−
Type-C 侧USB1.6 / USB1.8 → R37.1USB1.5 / USB1.7 → R39.1
串阻后R37.2 → U5.33R39.2 → U5.32
  • 等长：两段总长差 < 50 mil
  • 并行走：间距恒定 6–8 mil，全程不分开
  • 少过孔：能在一层走完就不要换层
  • 底层对应区域铺地，不要有其他信号穿过

另外 R36.1 也接在 DP 上（1.5kΩ 上拉，经 Q1 到 3.3V），这是 USB 枚举控制，走线可以普通，但要靠近 D+ 分支点。

CC1：USB1.4 → R40.2、CC2：USB1.10 → R31.1，各 5.1kΩ 下拉，普通走线即可。

05

P3 · 晶振

修好网络后，两组各自独立：

组网络连接点
主控OSC_IN / OSC_OUTU1.5 / U1.6 · X1 · C11 · C12
ST-LinkOSC_IN_STL / OSC_OUT_STLU5.5 / U5.6 · X2 · C24 · C25
  • 晶振到 MCU 距离 < 10 mm，两根线等长
  • 负载电容紧贴晶振引脚，不要放在 MCU 那侧
  • 晶振正下方的两层都不要走线，用禁布区圈起来
  • 晶振周围包一圈地，打过孔接地

NRST 上挂了 8 个点，其中 U1.7 和 U5.7 都是 MCU 的复位脚。这是板载 ST-Link 的常规做法——调试器要能复位目标芯片。走线时先连 U1，再分支到排针和 U5。

07

可以交给自动布线的

  • BOOT0 / BOOT1 的下拉电阻（R4/R16、R5/R24）
  • LED 及其限流电阻
  • SW1 按键
  • 反馈与分压电阻的细支
  • I2C 的 PB6/PB7（有上拉，速率低）
  • PA9/PA10 串口线
自动布线前务必锁定前面所有手动线。全选手动布的线 → 右键 → 锁定，然后再跑自动布线。跑完检查三件事：

· 有没有线宽被改小（尤其电源）
· 地平面有没有被切成孤岛
· 有没有锐角走线
08

另一个可选的修改

BOOT0 和 BOOT1 也是两个 MCU 并联：

  • BOOT0：U1.44 · U5.44 · R4.1 · R16.2
  • BOOT1：U1.20 · U5.20 · R5.2 · R24.1

后果是：给 ST-Link 升级固件、需要拉高 BOOT0 时，主控也会一起进入系统存储器启动，程序停止运行。做实验的时候会表现为"升级完 ST-Link，主控就不动了"。

如果不想改，可以留着——升级时不跑主控，实际影响不大。想干净一点的话，在原理图里把 U5 的 BOOT0/BOOT1 拆成独立网络即可。
